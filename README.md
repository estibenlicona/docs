# 🏆 PES 2021 – Torneo Eliminación Directa

Aplicación web para generar **torneos de eliminación directa** en PES 2021.  
Fácil y rápido: agrega los participantes con sus equipos, sortea y juega.

## Características
- Hasta **32 participantes**
- **Sorteo aleatorio** de cruces con un clic
- **Llaves visuales** ronda a ronda
- Haz clic en el ganador de cada partido para avanzarlo automáticamente
- Soporte de **BYEs** automáticos cuando el número de participantes no es potencia de 2
- **Campeón** destacado al final del torneo

## Uso
1. Abre la app (URL de Vercel o `index.html` localmente)
2. Agrega jugadores con su nombre y equipo PES 2021
3. Clic en **🎲 Sortear y Generar Llaves**
4. Por cada partido, haz clic en el jugador ganador para avanzarlo
5. ¡Disfruta el torneo!

## Deploy en Vercel
1. Importa este repositorio en [vercel.com](https://vercel.com) → **Add New Project**
2. Deja la configuración por defecto (no requiere build)
3. Haz clic en **Deploy** — listo ✅

## Stack
- HTML · CSS · JavaScript vanilla (sin dependencias)
